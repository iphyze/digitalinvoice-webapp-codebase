# DigitalInvoice NG frontend

Vite + React single-page app for DigitalInvoice, deployed as static files to cPanel.

- `npm install`
- `npm run dev`: local development (set `VITE_API_BASE_URL` in `.env`)
- `npm run build`: production build in `dist/`; upload everything in it, including `.htaccess`

Read `docs/BUILD-GUIDE.md` for architecture, the design system and conventions, and `design/` for the approved design.
